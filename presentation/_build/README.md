# Rebuilding the deck and script

`../SPY_Model_Presentation.pptx` and `../Presentation_Script.md` are both generated by `build_presentation.js`. Edit the text there (each slide's script is in its `note(s, ...)` call), then rebuild both, so the slides and the script never drift apart.

| File | What it is |
|---|---|
| `build_presentation.js` | Builds the deck (pptxgenjs) and writes the script (Markdown) |
| `money_paths.py` | Recreates v1's daily $100,000 paths from `outputs/test_predictions.csv`, `outputs/val_predictions.csv` and the price snapshot. They match v1's vectorbt results to the dollar. |
| `v1_money_paths.json` | Output of `money_paths.py`, used by the deck |

## Inputs

- `v1_money_paths.json` (this folder)
- `outputs/v2/results.json` (from `notebooks/v2_02_modeling.ipynb`) and `outputs/weekly/results.json` (from `notebooks/weekly_decisions.ipynb`).
- v3's numbers are typed into the script from `outputs/v3/calibration_report.md` and `development_report.md` (PRs #4, #5).

## Commands

Node and `pptxgenjs` are needed (`npm install pptxgenjs`).

The script also calls a theme helper (`apply_theme.js`, from the PowerPoint skill used to build this deck) through the `PPTX_SKILL` environment variable. Without it the slide colours fall back to Office's default palette. In that case, edit the `.pptx` directly in PowerPoint instead.

```bash
python presentation/_build/money_paths.py . presentation/_build/v1_money_paths.json
```

```bash
node presentation/_build/build_presentation.js presentation/SPY_Model_Presentation.pptx presentation/_build/v1_money_paths.json outputs/v2/results.json presentation/Presentation_Script.md outputs/weekly/results.json
```

The internal change note (`presentation/INTERNAL_*`) is kept out of git by `.gitignore`.
